# 👤 Emir — Oyun Arayüzü
📹 1. video: Drawing a Tetris block

## Görevler
- [ ] Mevcut oyun penceresini düzenle
- [ ] Oyun ızgarasını (grid) düzenle
- [ ] Puan alanını hazırla
- [ ] Seviye alanını hazırla
- [ ] Sıradaki blok alanını hazırla
- [ ] START düğmesini oyun işlemine bağla
- [ ] RESET düğmesini oyun işlemine bağla
- [ ] Diğer bölümler bitince alanları gerçek verilere bağla

## Dosyalar
| Dosya | Açıklama |
|-------|----------|
| `GameForm.java`       | Ana oyun penceresi (JFrame) |
| `GameArea.java`       | Izgaranın ve blokların çizildiği alan |
| `InfoPanel.java`      | Puan ve seviye göstergeleri |
| `NextBlockPanel.java` | Sıradaki bloğun gösterildiği alan |
| `StartMenu.java`      | START / RESET düğmelerinin bulunduğu menü |
